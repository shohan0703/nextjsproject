# FitLog

FitLog is a responsive workout library web application where users can explore workouts, view detailed exercise information, save workouts for later, and build their personal workout plan.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- JavaScript
- REST API
- LocalStorage

## Key Features

1. **Workout Library**
   - Browse a complete collection of workouts.
   - Responsive workout card layout for different screen sizes.

2. **Workout Details**
   - View detailed information about each workout.
   - Includes description, equipment, difficulty, sets, reps, duration, calories, rating, and instructions.

3. **My Plan**
   - Add workouts to today's workout plan.
   - View planned workouts and track completed exercises.

4. **Save Workouts**
   - Save workouts for later.
   - Saved workouts remain available even after refreshing the page using LocalStorage.

5. **Workout Sorting**
   - Sort workouts by Duration, Calories, or Rating.
   - Duration is selected by default.

## Project Features

- Responsive design for mobile, tablet, and desktop.
- Dynamic workout data fetched from an API.
- Persistent workout plan and saved workouts using LocalStorage.
- Toast notifications for workout actions.
- Custom workout detail pages.
